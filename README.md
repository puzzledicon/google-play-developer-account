## 建议阅读顺序

1. 先看注册 / 选型相关文章，完成账号开通与验证。  
2. 若需要付费能力，再看付款资料与内购开通。  
3. 最后进入测试、商店详情与提审清单。  
4. 全程回到官方 Console / Developer / 帮助中心完成实际点击。
